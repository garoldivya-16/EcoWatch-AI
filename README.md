# 🌍 EcoWatch AI

## Smart Waste, Pollution & Environmental Compliance Management System

EcoWatch AI is a smart environmental monitoring and management dashboard developed using Python and Streamlit. The system analyzes waste collection and pollution data to identify environmental risks, compliance violations, and management priorities.

---

## 🚀 Live Demo

🌐 **EcoWatch AI Dashboard:**  
https://ecowatch-ai-divya.streamlit.app

---

## ✨ Features

- 📊 Interactive environmental dashboard
- ♻️ Waste collection analysis
- 🌫️ Air Quality Index (AQI) monitoring
- ⚠️ Smart risk detection
- 🚨 Environmental compliance monitoring
- 🗺️ Zone-wise environmental analysis
- 🏆 Zone performance ranking
- 🤖 Smart management recommendations
- 🔍 Interactive filters for zones and districts
- 📋 Environmental data explorer
- 📥 Data download functionality

---

## 📊 Key Performance Indicators

The dashboard provides:

- Total Waste Collected
- Average Air Quality Index
- Critical Risk Areas
- Compliance Violations

▶️ Run Locally

Clone the repository:

git clone https://github.com/garoldivya-16/EcoWatch-AI.git

Install the required libraries:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run app.py
